# Abstract

VPNs vs. Proxies: A Comparison of Speed and Privacy

For this project, I will be building a testing environment to compare how VPNs and proxies function in a real networking setup. I plan to manually configure a VPN and a SOCKS5 proxy server to observe their behavior firsthand. My goal is to see exactly how these tools intercept and reroute data packets between a client and the internet. By setting up the servers myself, I will be able to demonstrate the configuration process and show how the network path changes when these tools are active compared to a standard, unprotected connection.

Once the setup is running, I will conduct a series of live experiments to collect my own performance data. I will run speed and latency tests to measure the overhead caused by VPN encryption and compare it to the lighter, unencrypted traffic of a proxy. I also plan to use a packet sniffer to inspect my own network traffic, providing visual proof of which data is being hidden from the outside world and which remains visible. By performing these tests myself, I aim to show the practical trade offs between speed and security, proving when it is more effective to use one technology over the other based on results I am going to study.
